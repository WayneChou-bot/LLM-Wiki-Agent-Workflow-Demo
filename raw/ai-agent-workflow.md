# AI Agent Workflow Demo Notes

An AI agent workflow can be presented as a sequence of roles that transform raw material into durable knowledge and action.

The programming role extracts implementation patterns, architecture decisions, integration constraints, and reusable code practices. It cares about how a system is built and how future developers can maintain it.

The UI design role extracts user journeys, screen states, interaction controls, visual hierarchy, and usability risks. It cares about whether a user can understand and operate the system.

The project management role extracts goals, scope, dependencies, roadmap, risks, and decisions. It turns raw information into an execution plan.

The personal knowledge role extracts learning loops, reflection prompts, review habits, and reusable mental models. It turns a project into a long-term knowledge asset.

For a demo, the same source can be ingested from different agent perspectives. The result is not one summary, but several durable wiki pages that preserve different kinds of expertise.

The strongest demo pattern is:

1. Ingest a source with the Programming Agent.
2. Ingest the same source with the UI Design Agent.
3. Ingest the same source with the Project Manager Agent.
4. Ask a cross-agent question.
5. Save the answer as a synthesis page.
