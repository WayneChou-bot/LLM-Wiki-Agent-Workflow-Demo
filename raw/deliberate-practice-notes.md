# Deliberate Practice Notes

Deliberate practice is the structured kind of practice that drives real skill growth. It is not the same as hours logged. The difference matters because most adults plateau by repeating what they can already do.

The four ingredients that define deliberate practice: a clear sub-goal that targets one weakness, immediate feedback that tells you whether the attempt worked, repetition that is hard enough to force adjustment, and a coach or system that points out what to work on next.

A personal learning loop that uses this idea looks like: pick one narrow skill, define a measurable check, run a short session, review what failed, adjust the next session. The session length matters less than the review.

The biggest failure mode is busywork dressed as practice. Reading more articles, watching more talks, attending more meetings — these feel like learning but lack the feedback and adjustment steps. The fix is to ask, after every session, what specifically improved and how you know.

A useful reflection prompt at the end of the week: which sessions actually changed what I can do, and which were just consumption. Track the ratio over time. The goal is not to eliminate consumption — it is to notice when the ratio has tipped too far.

This connects to longer-term knowledge accumulation: deliberate practice builds the underlying skill, but a personal knowledge system captures the lessons so they survive past the practice session. The two work together. Practice generates the experience; the knowledge layer keeps it durable.
