# Personal CRM Product Brief

A personal CRM is a small system for keeping track of relationships outside of work — friends, family, mentors, weak ties — that would otherwise drift.

The product goal is to help a single user remember context about people: when they last talked, what topics matter to that person, what follow-ups were promised, and what to bring up next time.

The core user journey has three loops. First, capture: after a conversation the user logs a short note about what happened and what to follow up on. Second, recall: before the next interaction the user opens that person's page and re-reads the last few notes. Third, prompt: the system surfaces relationships that have gone quiet and suggests a small reach-out.

A useful MVP scope: one note type, one tag dimension (relationship strength), one reminder rule (no contact in N days). No teams, no shared records, no automation. The system is for one human and their address book.

Risks to highlight in any roadmap: data sensitivity (this is the user's social graph; encryption and local storage matter), churn (people get added but never revisited; the surface needs to invite a daily five-minute pass), and creepiness (reminders that feel like surveillance kill trust).

Dependencies: a stable input method (mobile capture is more important than desktop), a simple data model (people, notes, follow-ups), and a quiet notification system that defaults to weekly rather than daily.

The success metric is not number of people tracked. It is number of relationships where the user can say, six months from now, that the system helped them stay in touch.
